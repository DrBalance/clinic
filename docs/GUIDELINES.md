# Dr. Balance 홈페이지 제작 지침 (요약·준수)

브랜드: Dr. Balance  
위치: 서울 강남구 논현동 37-16 (학동역 권역)  
운영: 원장 1인 소규모 한의원  
원장: 한의사 경력 17년, M-Test 한국 도입·보급, 「Dynamic M-Test」 저자, 테이프침 전문

홈페이지 역할: 네이버 블로그·플레이스·인스타에서 넘어온 사람의 신뢰 확인·예약. 검색 유입 본진 아님. 페이지 완성도 우선.

컨셉: **스트레스가 몸에 남긴 것을 푸는 한의원**
톤: 차분하게 설명해 주는 전문가. 짧은 문장, 몸의 언어, 존댓말 설명체. 영업 말투·과장 금지.
시각: Japandi, 여백, 색 2~3가지, 제목 명조·본문 고딕. 스톡 의사/침 모델 사진 금지. 손그림 인체 일러스트(자리만). 모바일 기준.

침 포지션: 증상 중심. "빠르게 낫는다" 금지. "빠르다"=치료 시간 짧음. 핵심: **점심시간 20분, 붙이고 복귀**.
급여 침 본인부담 약 10,500원 공개. 테이프침+추나 프로그램은 이름·가격 미확정 → 자리만.
테이프 노출 FAQ: 옷 안쪽·촬영 전 제거 가능 안내.

사이트 구조:
홈
├─ 침 치료 (소개, 20분, 비용)
│   ├─ 목·어깨 긴장
│   ├─ 두통·편두통
│   ├─ 허리·골반 통증
│   └─ 발목·종아리 통증과 다리 부종
├─ 한약
│   ├─ 소화불량·역류성
│   ├─ 두드러기
│   └─ 불안·불면
├─ 처음 오시는 분
├─ 원장 소개
└─ 오시는 길·진료시간·예약

증상 페이지 순서: 이런 분 → 왜 생기는가 → 어떻게 치료 → 비용·예약 → 관련 링크
목·어깨를 템플릿으로. 업로드된 `01-목어깨-긴장.md` 문안 사용.

의료광고 금지: 효과 보장, 완치, 전후사진, 미용 효과, 연예인 이용 언급, 최고/유일 비교.

에이전트가 임의로 채우지 말 것 (자리만 표시):
- 한약 주력 순서(소화 vs 두드러기)
- 대표 테이프침 증상(홈 카피)
- 진료시간, 점심예약, 전화번호, 네이버 예약 URL
- 테이프침+추나 프로그램 이름·가격
- 각 증상 원인 기전 의학적 원문 (원장 제공). 종아리·아킬레스 관점은 1~3번 원인 섹션 구조에 자리만 두고 구체 기전은 비울 것.
- 통계·가격은 이 문서에 있는 것만

타깃: 20~30 사무직 + 연습생/모델. 페이지를 타깃별로 나누지 말 것. "오래 앉아 있는 몸 / 오래 서 있는 몸"으로 묶기. 연예인 한의원 인상 금지.
