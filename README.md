# clinic

아침나라한의원 홈페이지 (Astro, GitHub Pages).

## 질문과 답변 추가하기

각 진료 페이지 아래의 "자주 묻는 질문"은 `src/content/qa/<진료 페이지>/` 폴더의 파일 하나가 질문 하나입니다.
파일을 추가하면 해당 페이지의 아코디언에 자동으로 들어갑니다.

```md
---
page: acupuncture        # 붙을 페이지: acupuncture, digestion, sleep, urticaria, herb, faq
category: 침에 대해      # 주제 묶음 이름 (같은 이름끼리 한 묶음으로 보입니다)
question: 침이 아프지 않나요?   # 환자가 묻는 말 그대로
order: 130               # 작을수록 먼저. 묶음은 그 안의 가장 작은 번호 순서로 나열됩니다
draft: true              # 선택. true 이면 사이트에 표시하지 않습니다 (답 검토 전)
---
여기에 답을 씁니다. 줄바꿈이 그대로 유지됩니다.
```

- 답 안에서는 `###` 소제목을 쓰지 않습니다 (아코디언 규칙과 겹칩니다).
- 번호는 100 단위로 묶음을 나누고(110, 120 … / 210, 220 …) 사이에 여유를 두면 나중에 끼워 넣기 쉽습니다.
- 질문마다 주소가 생깁니다. 파일 이름이 `02-tape-needle.md` 이면 `/acupuncture#qa-02-tape-needle` 로 연결하면 해당 질문이 펼쳐진 채 열립니다.
